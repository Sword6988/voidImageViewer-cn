## 这是什么

Void Image Viewer 是一款轻量的 Windows 看图工具，界面文本全部内嵌在可执行文件里，没有语言包机制。

本仓库提供一套**完整的汉化工具链**，把原版 `voidImageViewer.exe` 重新生成为一个全中文的可执行文件：

- **覆盖范围**：主菜单与菜单项、选项对话框、工具栏提示、状态栏、文件对话框、关于信息等，共 **223 条译文**（另有 59 处刻意保留原文，见对照表）。
- **单文件替换**：生成的汉化版与原版同名同目录，放回 `C:\Program Files\voidImageViewer\` 覆盖即生效。
- **版本自适应**：不依赖硬编码地址。程序发布新版本后，**无需修改本仓库任何代码**，重跑一次即可完成汉化。
- **零依赖**：纯 Python 标准库实现，不需要 `pip install` 任何东西，也不需要联网。
- **可回退**：汉化前自动备份原版，一键还原，还原后与原版 **MD5 完全一致**。

> 本仓库**不包含**任何 Void Image Viewer 的程序文件。使用者需自备合法副本，用本仓库脚本自行生成汉化版。

## 三步使用流程

### 第 1 步：安装原版

从官方渠道下载安装 Void Image Viewer（默认安装到 `C:\Program Files\voidImageViewer\`）。

### 第 2 步：执行汉化

在 `cn_pack\` 目录下，**右键 `汉化.bat` → 以管理员身份运行**。

脚本会自动完成：备份原版 → 生成汉化版 → 覆盖安装目录 → 启动程序自检。

> 写入 `C:\Program Files` 需要管理员权限。若不想动安装目录，可改用 `仅生成.bat`，产物在 `cn_pack\cn_out\voidImageViewer.cn.exe`，自行复制替换。

### 第 3 步：确认结果

看到输出 `自检结论：菜单已为中文 ✅` 即完成。程序此时已是全中文界面。

**回退**：双击 `cn_pack\还原.bat` 即可恢复英文原版。

## 工作原理

本方案不改动程序的任何原有代码逻辑，而是**在保留原版全部代码的前提下，追加一个可执行节 `.cnstr` 存放 UTF-8 中文译文**，再把原本指向英文的引用重定位过去。五步流程：

| 步骤 | 说明 |
| --- | --- |
| ① 内容签名定位 | 字符串按**原文内容**在翻译表中查表匹配，而非按地址 |
| ② 译文重定位 | 全映像扫描 8 字节绝对指针 + 手工解码 `.text` 中的 RIP-相对 `LEA` |
| ③ 挂钩修复 | 按**稳定字节模板**搜索代码钩子（拓宽循环 45 B 模板、UTF-8 转换函数 33 B 模板） |
| ④ 资源重建 | 重新构建 `.rsrc` 中的 DIALOG 资源，保留尾部对齐填充 |
| ⑤ 布局收尾 | 新节 RVA 由最后一节自动推算；重算 PE 校验和、节区数、映像大小；原样搬运 overlay 数字签名 |

因为每一步都是**现场扫描**而非地址写死，所以字符串增删、节区增减、代码重排都不会导致失效。

**附带修复**：程序内部有 5 处内联的「逐字节 1:1 拓宽」循环，它把 ANSI 字节直接当作宽字符存入 ListBox，只对 ASCII 有效，汉化为 UTF-8 中文后必然乱码。本工具将这 5 处循环重定向到一个新增代码洞，先按原规则剥离 `&` 助记符，再调用程序自带的 `MultiByteToWideChar(CP_UTF8)` 包装函数。

## 系统要求

- **操作系统**：Windows x64（Void Image Viewer 本身为 x64 原生 PE）
- **Python**：3.8 及以上，**仅使用标准库**
- **权限**：覆盖 `C:\Program Files` 需管理员权限
- **网络**：不需要

脚本按以下顺序查找 Python 解释器：

1. `cn_pack\runtime\python.exe`（自带便携版时）
2. 系统 `PATH` 中的 `python`
3. 系统 `PATH` 中的 `py` 启动器

均未找到时会给出明确提示。

## 注意事项

1. **数字签名失效**：覆盖后原 Authenticode 签名段虽被原样搬移，但文件内容已变，签名不再有效。未签名程序 + 新增可执行节可能触发杀软启发式告警，属正常现象，请自行加白名单或改用 `仅生成.bat` + 手动替换。
2. **配置文件副作用**：程序会把快捷键等设置写入 `%APPDATA%\voidImageViewer\voidImageViewer.ini`，键名由命令名派生。汉化后少数组名可能重名，但**快捷键取值不受影响**，无设置丢失。
3. **幂等**：若目标 exe 已是汉化版（含 `.cnstr` 节），脚本会自动改用 `备份\` 中的原版重建，因此可安全地重复双击。
4. **新增词条**：若新版程序新增了英文文本，脚本不会报错，而是打印「未命中」清单；按原文补进 `translations.py` 即可。
5. **已知未落地项**：文件类型项 `*.* (All Files)` 在原映像中无任何引用，且中文译文超长会溢出，未做替换。
